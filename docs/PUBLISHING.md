# 发布范围

包含：管理器源码、通用标签与角色种子库、两套插件源码、图标、合成测试及使用说明。
保留模型管理和图文笔记功能，首次运行时为空。

不包含：

- 作者的模型清单、模型路径、来源索引、提示词图片组、模型封面与模型权重。
- 作者的图文笔记、分组数据、正文与附件图片。
- 本地浏览器设置、手工模型网址、历史备份、缓存、截图、测试输出、已编译托盘 EXE。
- 本机用户路径及安装目录。

整个运行目录 `manager/data/` 均被忽略，个人配置 `config.local.json`、插件 `config.json` 也被忽略。
请勿使用 `git add -f` 强行添加运行数据。
发布前运行 `python -X utf8 tools/check-publication.py`，并检查 `git diff --cached --name-only`。
可以运行 `git config core.hooksPath .githooks` 启用本仓库的提交前检查；克隆后需要重新设置一次。
本仓库未包含任何旧 Git 历史；不要将带个人数据的旧提交合并进来。

运行检查会拒绝被 Git 跟踪的个人数据目录、配置、备份、编译输出及包含个人内容的发布包。
本项目当前没有选定开源许可证；在添加许可证前，请先确定代码和种子数据各自的授权范围。
